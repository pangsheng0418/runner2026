# TUR 路跑活動線上報名與管理平台

獨立運作的線上路跑活動報名與管理平台，採用**單一統一 Google 試算表雲端資料庫架構**與**多承辦人分層權限隔離**設計，專為網路部署（Vercel）打造。

## 核心特色

- **純粹獨立報名首頁**：首頁僅列出所有「**開放中**」賽事（不顯示名額），依**賽事月份（YYYY 年 MM 月）條列呈現**並支援同畫面展開詳細摘要。
- **個人與團體報名（可命名）**：支援單人報名與多成員團體報名，兩種方式皆可選擇**個別匯款**或**團體匯款**並記註**匯款帳號尾五碼**。
- **輸入當下即時檢核**：身份證字號／護照號碼檢核碼、**限滿 16 歲以上**實歲驗證、**台灣手機 10 碼**、Email 格式與尾五碼皆於輸入當下即時提示。
- **Email 通知與反向查詢改報**：報名成功、改報更新與承辦人核帳完成皆自動寄送 Email；選手可透過雙因子驗證（身分證＋序號或 Email）反向查詢狀態、補填尾五碼或修改資料。
- **多承辦人分層權限**：一般承辦人僅管理自己建立的活動（互不干擾）；**最高權限承辦人**可管理全平台所有活動、修改所有承辦人權限，並操作**一鍵載入測試資料、資料完整備份與還原、資料清空**。
- **統一單一 Google 試算表資料庫**：進入系統自動指向同一份雲端試算表，無需為每個活動各建連結。

## 快速啟動

```powershell
npm.cmd install
npm.cmd run build
npm.cmd start
```

- **前台報名平台**：`http://localhost:3000`
- **選手反向查詢與改報**：`http://localhost:3000/lookup`
- **後台管理入口**：`http://localhost:3000/admin/login`（預設最高權限帳號：`admin` / `runner2026`）
