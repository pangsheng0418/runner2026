# TUR 路跑活動線上報名與管理平台

獨立運作的線上路跑活動報名與管理平台，全站採精簡清爽介面、**單一統一 Google 試算表雲端資料庫架構**與**多承辦人分層權限隔離**設計，專為網路部署（Vercel）打造。

## 核心特色

- **精簡清爽首頁與月份條列**：首頁僅列出「**開放中**」活動（不顯示名額），依**賽事月份（YYYY 年 MM 月）條列呈現**並支援同畫面展開摘要。
- **個人與團體報名（可命名）**：支援單人與多位團員報名，皆可選**個別匯款**或**團體匯款**，**匯款帳號尾五碼預設必填**。
- **輸入當下即時檢核 ＋ 日期連動**：
  - **身份證字號**（取消護照字樣）：合計 10 碼，第 1 碼英文、第 2 碼僅限 `1`（男）或 `2`（女）、檢核碼驗證，並與「性別」欄位**雙向即時核對**。
  - **出生年月日**：西元年（含民國年）／月／日三欄即時連動＋日曆雙向同步，年齡限制 **10～80 歲**。
  - **連絡電話**：統一台灣手機 10 碼（`09` 開頭）；**電子信箱**與**尾五碼**同步即時驗證。
- **Email 通知與反向查詢改報**：報名成功、改報更新與承辦人核帳完成皆自動寄送 Email；選手可憑「身份證字號＋報名序號或 Email」反向查詢與改報。
- **多承辦人分層權限**：一般承辦人僅管理自己建立的活動；**最高權限承辦人**可管理全平台活動、所有承辦人權限及**載入測試資料、完整備份與還原、清空資料**。
- **統一單一 Google 試算表資料庫**：進入系統自動指向同一份雲端試算表，免逐場設定連結。

## 快速啟動

```powershell
npm.cmd install
npm.cmd run build
npm.cmd start
```

- **前台報名平台**：`http://localhost:3000`
- **選手反向查詢與改報**：`http://localhost:3000/lookup`
- **後台管理入口**：`http://localhost:3000/admin/login`（預設最高權限：`admin` / `admin1234`）
